# Streamer Clips – media

Public hosting for the finished 9:16 Shorts and thumbnails that are posted to the
**Streamer Clips** TikTok and YouTube accounts through Metricool.

Each clip lives in its own folder:

```
clips/<date>_<streamer>/<id>/
  <id>.mp4          the finished Short (9:16, 1080x1920)
  <id>_thumb.jpg    the cover / thumbnail
  <id>_post.txt     title, description and hashtags used for the post
```

The clips are made with the `clipping` skill (live stream → chat-spike detection →
captioned Shorts).

## Credit

Every clip is taken from the original creator's live stream and credits them on screen
and in the post description, with a link to their channel. All rights to the original
footage belong to the creator. If you are a creator and want a clip removed, open an
issue in this repository and it will be taken down.
